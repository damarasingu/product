# product

A minimal wishlist tool to store products you like or want to buy for future reference.

## Usage

```bash
python wishlist.py add "Noise Cancelling Headphones" --kind like
python wishlist.py add "Standing Desk" --kind want_to_buy
python wishlist.py list
```

Saved data is stored in `/home/runner/work/product/product/wishlist.json`.
